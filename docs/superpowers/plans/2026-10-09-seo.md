# SEO & Shareable Render Previews — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Crawlable, per-page-optimised HTML (25 system pages + help + studio), a sitemap with images, real 404s, and share cards that show the exact shared render.

**Architecture:** Keep Create React App. A pure-data system catalog feeds everything non-UI. System write-ups move out of `Info.tsx` into per-system modules rendered by `/info` and new `/systems/:slug` pages. A post-build Node script (esbuild + React server rendering + styled-components `ServerStyleSheet`) writes static HTML per route plus `sitemap.xml`/`404.html`. A Vercel Function (`api/og.ts`) renders share PNGs with the real `public/worker.js` (vm sandbox) and `sharp`; Vercel Routing Middleware (`proxy.ts`) injects per-render share tags into shared studio links.

**Tech Stack:** React 18.2, react-router-dom 6.14 (`react-router-dom/server` StaticRouter), styled-components 6.1, TypeScript 4.9, CRA 5 / Jest 27, esbuild (new devDependency), sharp 0.34 (existing), `@vercel/functions` (new dependency), Vercel `vercel.json`.

**Spec:** `docs/superpowers/specs/2026-10-09-seo-design.md`

## Global Constraints

- Canonical origin: `https://chaos-iterator.vercel.app` (constant `SITE_ORIGIN` in `src/seo/site.ts`).
- Help content must not change: `src/__tests__/InfoContent.test.tsx` (34 images, 25 system names, 12 sections, lazy images) stays green; card text is byte-identical before/after the split (fixture test).
- No React import may reach `src/attractors/catalog.ts` or `src/seo/*` modules used by `api/` or `proxy.ts` (type-only imports allowed).
- Shared-link canonical always stays `https://chaos-iterator.vercel.app/`.
- Studio (`/`) is never server-rendered; its static HTML gets meta + JSON-LD + `<noscript>` links only.
- Tests: `CI=true npx react-scripts test --watchAll=false` — the 7 known `iteratorConfig.test.ts` failures (pre-existing) are the only allowed failures. App lint: `npx eslint src --ext .ts,.tsx --ignore-pattern "src/__tests__/**"` clean. `CI=true npm run build` must pass.
- Commit after every task, message ending `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Branch `seo`.

## Review Focus

1. A system page URL that doesn't exist (`/systems/nope`) → 404 page in the app and HTTP 404 from Vercel (not a 200 shell). → Task 3 test + Task 5 config check.
2. Shared link with junk params (`?type=clifford&alpha=abc`, out-of-range numbers, unknown `type`) → OG renders with defaults/clamped values, unknown type → 404; middleware falls through. → Task 6/7 tests.
3. Server rendering touching browser-only APIs (`document`, `window.matchMedia`, `Worker`, Giscus) crashes the build. → Task 5 prerender test renders every route.
4. Duplicate/conflicting `<title>`/canonical tags after client navigation (prerendered tags + client hook). → Task 4 `useDocumentMeta` test replaces, not appends.
5. Very heavy fractal params in a shared link (maxIter 100000, zoom 1e12) making `api/og` exceed limits. → Task 6 clamps maxIter (≤ 2000) and time-boxes.
